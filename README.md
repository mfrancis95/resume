# Resume

This is my professional resume built with [RenderCV](https://github.com/rendercv/rendercv).

## Prerequisites

- Python 3.10 or higher
- pip (Python package manager)

## Installation

Install the required dependencies:

```bash
pip install -r requirements.txt
```

This will install RenderCV with all optional dependencies.

## Building the Resume

To generate the resume in multiple formats (PDF, HTML, Markdown, PNG):

```bash
rendercv render resume.yaml
```

The generated files will be placed in the `rendercv_output/` directory.
